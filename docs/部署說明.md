# 部署說明（第 1 階段）

全部步驟都用**學校帳號**操作。一共四個步驟，第一次大約需要 20 分鐘。

---

## 步驟 1：確認試算表

試算表裡要有三個工作表，**名稱和第一列的欄位名稱必須完全相同**：

| 工作表 | 第一列欄位 |
|---|---|
| 車牌名單 | 車牌號碼、汽機車、單位、職稱、姓名、行動電話、Email |
| 授權登入名單 | Email、姓名、備註 |
| 下載紀錄 | 時間、Email、結果、筆數、裝置 |

- 「車牌號碼」統一寫成英文大寫加連字號，例如 `ABC-1234`。
- 「汽機車」只填「汽車」或「機車」。
- 「行動電話」建議把整欄設成**純文字**（格式 → 數字 → 純文字），開頭的 0 才不會不見。
- 「授權登入名單」先把**自己的 Email** 加進去，才能測試。
- 「下載紀錄」只要保留第一列欄位名稱就好，系統會自動寫入。

## 步驟 2：部署 Apps Script 後端

1. 在試算表上方選單點「**擴充功能 → Apps Script**」。
2. 把編輯器裡原本的程式碼全部刪掉，貼上本程式庫 [`apps-script/Code.gs`](../apps-script/Code.gs) 的全部內容，按 💾 儲存。
3. **執行一次設定檢查**：
   - 上方函式選單選 `testSetup`，按「執行」。
   - 第一次會跳出授權畫面：選自己的學校帳號 →「進階」→「前往（不安全）」→「允許」。
     （這是因為腳本是自己寫的，還沒經過 Google 審查，屬於正常現象。）
   - 下方「執行記錄」出現「✅ 設定檢查通過」才繼續。如果出現「缺少欄位」或「找不到工作表」，請回到步驟 1 修正。
4. **部署**：
   - 右上角「部署 → 新增部署作業」。
   - 齒輪圖示選「**網頁應用程式**」。
   - 說明：`v1`
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按「部署」，複製「**網頁應用程式網址**」（結尾是 `/exec`）。
5. 用瀏覽器開啟這個網址，看到 `{"ok":true,"service":"WES_LPR"}` 就代表部署成功。

> **為什麼存取權限要選「所有人」？**
> 這只是讓手機可以呼叫這個網址。每次呼叫，後端都會驗證 Google 登入憑證、檢查是否為學校網域、是否在授權登入名單中，沒通過就拿不到任何資料。試算表本身仍然不分享給任何人。

### 以後修改 Code.gs 時

要用「部署 → **管理部署作業** → ✏️ 編輯 → 版本選『新版本』→ 部署」。
**不要**用「新增部署作業」，否則網址會改變，前端也要跟著改。

## 步驟 3：設定前端

打開 [`js/config.js`](../js/config.js)，把步驟 2 複製的網址貼到 `API_URL`：

```js
API_URL: 'https://script.google.com/macros/s/xxxxxxxx/exec',
```

`CLIENT_ID` 已經填好，不用改。

## 步驟 4：開啟 GitHub Pages

1. 把程式推送到 GitHub 的 `main` 分支。
2. 到 GitHub 程式庫的「**Settings → Pages**」。
3. Source 選「Deploy from a branch」，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
4. 大約 1～2 分鐘後，網站會出現在：**https://chungyi.github.io/WES_LPR/**

之後每次推送到 `main`，網站會自動更新。

## 手機安裝（加入主畫面）

- **Android（Chrome）**：開啟網址 → 右上角 ⋮ →「加到主畫面」或「安裝應用程式」。
- **iPhone（Chrome）**：開啟網址 → 分享按鈕 →「加入主畫面」。

## 驗收檢查表

- [ ] 授權登入名單上的帳號，可以登入並下載名單
- [ ] 把自己暫時移出授權登入名單，再按「資料下載」→ 顯示「未授權」，手機資料被清除，下載紀錄出現「拒絕」
- [ ] 用非學校帳號（例如 @gmail.com）→ 無法登入
- [ ] 下載紀錄有正確寫入時間、Email、結果、筆數、裝置
- [ ] 手動查詢：完全相符、相近候選、查無資料三種情況都正確
- [ ] 資訊卡按「撥打電話」會叫出撥號畫面
- [ ] 登出後重新開啟網頁，需要重新登入
- [ ] 在 iPhone 的 Chrome 和 Galaxy S23+ 的 Chrome 上都測試過

## 常見問題

| 狀況 | 可能原因與處理 |
|---|---|
| 顯示「系統尚未設定後端網址」 | `js/config.js` 的 `API_URL` 還沒填 |
| 顯示「伺服器發生錯誤」 | Apps Script 部署的「誰可以存取」不是「所有人」；或工作表名稱、欄位名稱不對，可以在 Apps Script 的「執行作業」查看錯誤訊息 |
| 顯示「登入驗證失敗」 | 用的不是 @wes.tc.edu.tw 帳號；或 Code.gs 裡的 `CLIENT_ID` 和 config.js 不一致 |
| Google 登入按鈕沒出現 | Google Cloud 的「已授權的 JavaScript 來源」要有 `https://chungyi.github.io` |
| 電話號碼開頭的 0 不見了 | 把試算表「行動電話」欄設成純文字，重新輸入後再下載 |
| 更新程式後手機還是舊版 | 關掉網頁重新開啟一次（系統採用網路優先，通常會自動更新） |
